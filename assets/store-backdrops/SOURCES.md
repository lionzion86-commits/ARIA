# Store backdrop photo sources — ariashop.pe (sourced 2026-10-07)

All photos are real store interiors from Wikimedia Commons, verified to load (HTTP 200, image/jpeg),
landscape, ≥1200px wide, and visually inspected. Files live in this directory as `<storekey>.jpg`.

**Attribution:** every CC BY / CC BY-SA photo below must be credited wherever the site credits imagery
(photographer name + license). CC0 and public-domain photos need no credit but it is good practice.
