## What the pull must return: every shade of every product

Use one product page per worklist entry. Return **every** shade the store sells for that product, not only the one in `url`. This is the Walmart productDetails shape that `data/shades-walmart-2026-11-01/dataset.json` already uses. The ingest reads it for any store:

```json
[
  {
    "usItemId": "2640692",                     // this page's own shade SKU
    "name": "Slim Lip Pencil Lip Liner",       // the product title
    "brand": "NYX Professional Makeup",
    "url": "https://www.ulta.com/p/...?sku=2640692",
    "variantList": [
      {
        "usItemId": "2640692",                 // the shade's own SKU / item id (sku=, skuId=, pid., .product.N.html)
        "url": "https://www.ulta.com/p/...?sku=2640692",   // the shade's own URL, carrying that SKU
        "variants": ["actual_color-820 Espresso"],         // "actual_color-" + shade NUMBER and NAME, as the store writes them
        "priceInfo": { "price": 5.0, "wasPrice": 6.0 },    // that shade's price (wasPrice only if on sale)
        "imageUrl": "https://…/2640692",                   // that shade's swatch or product photo
        "allImages": ["https://…/2640692", "https://…/2640692_alt01"],
        "availabilityStatus": "IN_STOCK"                   // or "OUT_OF_STOCK"
      }
    ]
  }
]
```

For each shade this gives the shade name and number (`actual_color-<number> <name>`), the SKU/item id (`usItemId`), its own URL, the swatch image (`imageUrl`, `allImages`), its price (`priceInfo.price`) and its availability (`availabilityStatus`). A multipack shade adds `"multipack_quantity-2"` to `variants` (a pack is never a shade). Never invent a shade: a product whose page lists none is left out.

How a pulled shade is matched to our listing: the catalogue listing and the pulled shade meet on the shade SKU in the URL (`scripts/lib/variant-families.mjs` `shadeSkuOf`). That is `?sku=` for Ulta, `?skuId=` for Sephora, `pid.N` for YesStyle, `.product.N.html` for Costco and the trailing id for Victoria's Secret. Macy's beauty goes through its own `colorMap` export, the Route A path in `scripts/build-macys-colourways.mjs`.

## Where to drop the result

- **Walmart:** `data/shades-walmart-<date>/dataset.json` (read by `readWalmartPulls`).
- **Any other store:** `data/shade-pulls-<date>/dataset-<store>.json`, for example `dataset-ulta.json` or `dataset-sephora.json` (read by `readStorePulls`; any folder under `data/` holding `dataset-<store>.json`).

Then regenerate:

```
node scripts/ingest-variant-pulls.mjs      # writes scripts/data/variant-families/<store>.json (families with a member in our catalogue)
node scripts/build-pdp-slices.mjs          # the «Tono» dropdowns; the gate lifts product by product
node scripts/build-price-index.mjs         # checkout prices every shade
node scripts/build-shade-worklist.mjs      # what is still missing
```
